# 更新日志

遵循语义化版本：功能新增升次版本，修复升修订号。

## 0.2.0 · 2026-10-24

**主题：任务封存（Seal）—— 记忆是本体，会话是工作台。**

### 新增

- **`task_seal` 工具**（第 5 个模型工具）：任务收尾时由 agent 主动调用，参数为任务名、已完成、关键决定、涉及文件、下一步、坑、关键命令。
- **任务卡**：写入 `工作记忆/实时记忆/当前任务.md`，固定结构、上限 800 字；超限按「任务 > 已完成 > 下一步 > 关键决定 > 坑 > 文件 > 恢复步骤」优先级截断。
- **会话摘要**：同时写 `实时记忆/日志/会话摘要/<时间>-<任务名>.md`，保留原始需求、过程、报错原文与回滚方法；不限长度、不注入、不占上下文。
- **封存后首步注入**：新会话第一步强制注入任务卡全文，首步预算 `firstStepChars`（默认 1500 字），替代原来的 300 字实时卡摘要。
- **面板按钮**：「封存并开新会话」，走 `/api/dsh-brain/seal`，5 秒内重复点击只执行一次。

### 改进

- `handoff.js` 抽出 `performHandoff(session, opts)`：接续与封存共用「写卡 → 建会话 → 继承模型/权限 → 归档 → 切换」流程。
- `inject.js`：识别「本会话由封存创建」（`sealRecordFor`），命中则直接注入任务卡，不再走检索。
- `paths.js`：新增 `firstStepChars` 设置项与 `sessionSummaryPath()`。
- `cards.js`：仅对 `当前任务.md` 放宽到 800 字，其余卡片仍按原上限。
- 中英文 locale 同步更新，描述加入「任务封存」。

### 安全与失败处理

- 拒绝封存：存在未完成的工具调用、上一轮有未完成 tool_call、会话轮次 < 2。
- 写卡失败 → 中止，旧会话不变；建会话失败 → 卡片保留并标记 `封存失败`；归档失败不阻塞。
- 不删除任何会话，不代发首条消息，生成过程中不切换。

### 测试

- 新增 `tests/seal-smoke.mjs`（封存全流程 + 拒绝条件 + 失败回滚）。
- 回归：`unit-smoke`、`handoff-smoke`、10 问对照（10/10）全部通过。

## 0.1.0 · 2026-10-23

首个公开版。

- 四层记忆：全局 / 项目 / 实时 / 日志，沿用 `sage-mem` 的目录与卡片格式。
- 每轮 BM25 检索注入（中文二元组 + 英文整词），top-2、单卡 600 字、每轮 2400 字预算。
- 自动接续：上下文阈值 80% / 单轮 150k / 60 轮，继承模型与权限并归档旧会话。
- 4 个工具：`memory_search`、`memory_read`、`memory_write`、`memory_digest`。
- 左侧边栏「记忆大脑」面板：卡片查看/编辑/删除、开关与阈值、立即接续/消化。
