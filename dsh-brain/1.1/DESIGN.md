# dsh-brain · 记忆大脑插件设计

> 一个插件同时提供：四层记忆体系 + 自动接续 + 左侧边栏记忆面板。
> **替代 `sage-mem`**，卸载后功能不得倒退。
> 交给创作模式实现；本文件是唯一依据。

## 目标（五条验收口径）

1. **跨对话**：新会话开头自动带画像 + 项目摘要，不用重新交代。
2. **跨工作区**：全局 3 张卡所有工作区共用；项目卡按工作区隔离，用《索引-项目》定位。
3. **自动开对话**：到阈值自动建新会话并切过去，模型 / 模式 / 权限全继承。
4. **自动归档**：旧会话自动归档（可搜索恢复），列表不堆积。
5. **不劣于现状**：卸载 `sage-mem` 后，注入、检索、工具、管理界面一项都不能少（见「七、回归对照」）。

这五条做不到，插件就算失败。

## 一、定位

| 能力 | 现在（sage-mem） | dsh-brain |
|---|---|---|
| 卡片存储 | 读 `D:\OpenAI\全局记忆` | 同一目录、同一格式，平滑接管 |
| 注入 | 每轮 top-k | 基线 1 张（每会话一次）+ top-2（≤600 字符/张），命中 0 条不注入 |
| 工具 | `search_memory` / `read_memory` | 4 个：search / read / write / digest |
| 管理界面 | 设置页 | **左侧边栏「记忆」面板** |
| 自动接续 / 归档 | 无 | 有 |

## 二、目录（沿用，不搬家）

```
D:\OpenAI\全局记忆\  user-画像.md（baseline）/ 索引-项目.md / 环境-机器.md
<工作区>\工作记忆\  项目记忆\{00-概况,01-决定,02-坑}.md
                    实时记忆\当前任务.md + 日志\*.md
```

## 三、注入（控制成本）

1. 会话首步：`user-画像.md` 全文（≤1300 字）+ 当前工作区 `00-概况` 摘要（≤120 字）。
2. 之后每轮：BM25 检索，最多 2 张、单卡 ≤600 字符；0 命中不注入。
3. 项目卡全文只在 `memory_read` 时进上下文。
4. 硬上限：每轮 ≤800 token，超了截断并记日志。

## 四、工具

`memory_search(query)` / `memory_read(file, from, lines)` / `memory_write(layer, file, content)` / `memory_digest()`（实时 → 项目）。

## 五、自动接续（80%）

触发（任一）：上下文 ≥80%、单轮 input >150k、会话 >60 轮；同会话只触发一次。

1. 覆盖写 `实时记忆\当前任务.md`（≤300 字）。
2. `session/create`：`{ workspaceId, agentPreset }`。
3. `session/selectModel` 继承 provider / model / reasoningEffort。
4. 继承权限：`permission/preset`、`sandbox/mode`、`approval/policy`。
5. `workspace/archiveSession` 归档旧会话（失败不阻塞）。
6. 发 `brain/handoff` → Client 导航 + toast「已接续」。

不删会话；不代发首条消息；正在生成时等本轮结束。

## 六、左侧边栏「记忆大脑」面板

**名称**：记忆大脑（图标 + 文字，左栏底部导航，与插件市场、上下文洞察同级）。

**面板内容**：
- 全局卡片列表：名称、描述、字数、最后修改；操作：查看 / 编辑 / 删除 / 打开目录。
- 项目区：当前工作区三张卡的入口 + 实时卡预览（只读）。
- 开关：自动接续（默认开）、阈值（默认 80%）、top-k（默认 2）、单卡上限（默认 600）。
- 按钮：立即接续、立即消化、打开记忆目录。
- 状态：上次接续时间、上次注入 token、卡片总数。

**实现**：client 半注册 sidebar 导航项 + 一个面板视图；数据走 Host 的 `brain/*` Remote 方法。

## 七、回归对照（卸载 sage-mem 前逐项打勾）

| 能力 | sage-mem | dsh-brain 要求 |
|---|---|---|
| 自动注入画像 | ✅ | ✅ 每会话首步 |
| 按需检索卡片 | ✅ | ✅ top-2 |
| 读全文 | ✅ | ✅ memory_read |
| 手动写/改卡 | 编辑文件 | ✅ memory_write + 面板编辑 |
| 查看卡片列表 | 设置页 | ✅ 左栏面板 |
| 打开目录 | ✅ | ✅ |
| 检索质量 | 现网基线 | **10 个真实问题命中数 ≥ 基线** |

**回归测试**：卸载前用 10 个常见问题（如「我是谁」「上次定过什么」「插件装在哪」）记录命中；换插件后重测，命中数不得下降，否则先修检索再卸载。

## 八、迁移与回滚

1. 安装后首次启动：接管现有目录与卡片，不迁移、不改格式。
2. 回归测试通过后再卸载 `sage-mem`；保留 `package.json.bak`。
3. 出问题：还原备份 + 重装 sage-mem，记忆文件不受影响。

## 十、消耗估算

**开发**（比纯接续插件多一个 UI 面板）：
- 请求 150–250 次，输出 80–150k token，缓存读 10–25M，未命中 200–400k；
- 非高峰约 **$0.12–0.30 ≈ ¥0.9–2.1**。

**运行**：
- 注入每轮 ≤800 token（多为缓存命中），与现在持平；
- 接续每次约 $0.002；
- 面板只读本地文件，无模型调用。

## 十二、交付与安装

- **源码位置**：`D:\OpenAI\仓库\dsh-brain\1.0\`（仓库按「项目 → 版本」组织：`仓库\dsh-brain\1.0`、`1.1`…，每个版本目录都是完整插件）。
- **开源发布**：同一目录即发布内容，不含内部提示词；再推到 GitHub `yesterday06/dsh-brain`。
- **包名**：`dsh-brain`；**面板名**：记忆大脑。
- **本地安装**：在 `~/.dsh/profiles/desktop` 里 `pnpm add link:D:\OpenAI\仓库\dsh-brain\1.0`，把 `dsh-brain` 加进 `dsh.profile.bundles`，重启验证。
- **卸载**：bundles 移除 → `pnpm remove dsh-brain` → 删目录。
- **改 profile 前**：先复制 `package.json` 备份。
- 源码要能直接 `git init` 后提交，不依赖本机绝对路径（路径走配置，不写死）。
- **成品归档（开源用）**：完成后
  1. `pnpm pack` 生成 `dsh-brain-<version>.tgz`，放进 `release/`；
  2. 把当前实际运行的 `node_modules/dsh-brain` 原样复制到 `release/installed/`；
  3. `release/BUILD.txt` 记录：版本、构建时间、DSH 版本、sha256；
  4. `node_modules`、`.pnpm` 等中间产物不进仓库，写进 `.gitignore`。

## 十一、风险

- 左栏导航槽位需确认 `dsh-client-ui-sidebar` 的注册方式，别和插件市场抢位置。
- `session/create` / `workspace/archiveSession` 从 Host 调用要先验证参数与权限。
- BM25 检索若不如 sage-mem，直接沿用它的打分逻辑，别自创。
- 卸载 sage-mem 前必须完成回归测试。
