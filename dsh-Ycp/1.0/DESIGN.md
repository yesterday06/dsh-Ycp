# dsh-Ycp · 大肥鱼 · 最终设计稿

> ⚠️ **0.2.0 起能力层已整层移除**：下面的「三只手 / 平台 / 自主解决」都是历史设计，重做能力层时再照着改。现在的她只有记忆和嘴。

> **Y** 是岔路，**c** 是童心，**p** 是人类。
> 一句话：一个**会用电脑、能自己上网做事**的 AI 个体。

---

## 1. 她不是"接了一堆接口"，是"会用电脑"

这是整份设计的地基，先说清楚：

| 错误做法 | 正确做法 |
|---|---|
| 给 QQ 写一个适配器、给 B站写一个、给小黑盒写一个 | 给她**一双手**，她自己会开、会登、会点 |
| 每加一个平台就写一次代码 | 每加一个平台，只要**给个账号、开个权限** |
| 她只会说，不会做 | 她会说，也会做 |

**主人只做两件事**：准备账号、打开权限。剩下的她自己来。

---

## 2. 三条腿

她所有的"上网做事"，都走这三条腿：

| 腿 | 能干什么 | 技术 | 风险 |
|---|---|---|---|
| **浏览器** | 开网页、登录、发帖、评论、看视频、填表单 | 控制一个 Chromium（Playwright） | 中（平台风控） |
| **桌面** | 操作任何程序：客户端、游戏、系统弹窗 | 截图 + 视觉理解 + 鼠标键盘 | 高（慢、贵、易错） |
| **脚本** | 没现成路，自己写个小工具 | 写文件 + 跑命令 | 低（沙箱内） |

三条腿的能力，就是她的"手"。

---

## 3. 一个例子：她说"我想玩 QQ"

```
她：我想玩 QQ
  ↓
① 查权限：浏览器开了吗？qq.com 在白名单吗？
  ↓ 没有 → 直接说"你还没给我开这个权限"
② 查账号：账号库里有 QQ 的号吗？
  ↓ 没有 → "给我个号呗"
  ↓ 有
③ 打开浏览器 → 进 qq.com → 填入账号密码 → 登录
  ↓
④ 看到什么说什么，想聊就聊，想发就发
  ↓
⑤ 遇到验证码 / 滑块
  ↓ 她过不去 → "卡在验证码了，你来看一眼"
```

全程**没有一行新代码**。主人只需要：给号、开权限。

## 6. 权限与账号

### 6.1 手（她能用哪条腿）

```json
{
  "hands": {
    "browser": true,
    "browserSites": ["qq.com", "bilibili.com"],
    "desktop": false,
    "desktopApps": [],
    "script": true,
    "runCommand": false
  }
}
```

- `browserSites` 是白名单：不在名单里的网站，她打不开
- `desktop` 默认关：这条腿最危险，开了才能操作游戏客户端
- `runCommand` 默认关：脚本可以写可以跑，但不许乱敲系统命令

### 6.2 账号库

`大肥鱼\账号\qq.json`：

```json
{ "site": "qq.com", "user": "123456", "secret": "……", "note": "小号" }
```

原则：
1. 主人放进去，她不外传
2. 只在对应站点用
3. 用之前先问一句"用这个号？"

### 6.3 三条铁律

**每项都有开关 / 关掉直接拒 / 越权记日志**

## 7. 上网闭环 + 自主解决

```
想知道 → 查 → 读 → 记住 → 下次直接用
```

遇到麻烦：

```
① 自己看（日志/文件/记忆）→ ② 想办法 → ③ 试
   ├ 成了 → 记住方法
   └ 没成 → 换办法，最多 3 次
④ 3 次都不行 → 记下"此路不通" → 求助
```

三道刹车：**3 次硬上限 / 每轮写日志 / 失败也进记忆**。

## 8. 人格与记忆

**人设**只有主人能改，模型看到全文原样，不总结。

| 记忆 | 放什么 | 检索 |
|---|---|---|
| 全局记忆 | 稳定事实 | ✅ 最高 |
| 归档记忆 | 过时但有用 | ✅ 打折 |
| 实时记忆 | 此刻在干嘛 | ✅ 必读 |
| 日记 | 情绪流水 | ❌ 不检索 |

**她没有成长阶段**。一开始就能用所有手，用得好不好靠积累。
今天登错一次，明天少错一次——这才叫长。

---

## 9. 作息与主动

- **界限**：安静时段、每小时上限、每天主动上限、话题黑白名单
- **自由**：几点睡、话多话少、先上哪个网
- **心情体力**：本地轻量算，只影响语气与主动频率
- **主动**：六道条件全满足才开口，冷却随机抖动 ±30%

---

## 10. 界面

- **DSH 侧边栏**：八页（她的今天 / 人设 / 记忆 / 作息 / 行为 / 外观 / 手 / 日志）
- **独立桌面窗口**：Electron 透明窗口
- **桌宠**：透明置顶、拖拽抛掷、待机/转向/点击动画、右键菜单、碎碎念、工作状态联动、多只
- **语音**：她说的话能出声（TTS），音色可选、可静音；语音输入与叫名字唤醒放后续
- **兼 whale**：余额查询、余量动画、低余额提醒
- **音效**：点击 / 说话 / 睡觉 / 吃饭 / 低余额，短、轻、可关
- **断网**：v1 做 A 档（预设行为，不崩）

## 11. 施工阶段（每阶段 ≈ 1 小时）

> 这是创作模式的施工顺序，不是她的日程表。
> 每格交付"一块能用的肌肉"，不规定她怎么用。
> **由主人发指令启动**：`开始 P1 创作`、`开始 P2 创作`……

| # | 阶段 | 交付 | 验收 |
|---|---|---|---|
| P01 | 包与入口 | 插件能装能加载 | 日志有一行 |
| P02 | 实例与设置 | 家目录、设置读写、HTTP | 改设置落盘 |
| P03 | 面板骨架 | 侧边栏 + 人设 + 试说 | 改人设 → 试说变调 |
| P04 | 记忆读写 | 四类目录、卡片解析 | 面板看到卡 |
| P05 | 检索与实时 | 打分、top-2、实时必读 | 不同问句命中不同卡 |
| P06 | 作息与闸门 | 作息表、五道闸 | 到点不说话 |
| P07 | 心情与统计 | 状态会动 | 说话后状态变 |
| P08 | 主动发言 | 到点自己冒一句 | 冷却内不重复 |
| P09 | 工具注册表 | 能力能挂 | 注册假工具能调用 |
| P10 | 上网四件套 | 查 / 读 / 记 / 想 | 查完能记住 |
| P11 | 浏览器之手 | 开页、点击、输入、截图、登录 | 能替她登进一个站 |
| P12 | 桌面之手 | 截图 + 鼠标键盘 | 能点开一个程序 |
| P13 | 脚本之手 | 读写文件、写脚本、跑命令 | 她能改自己日记 |
| P14 | 自主解决 | 3 次循环 + 求助 | 坏任务能自己收场 |
| P15 | 桌面窗口与形象 | 透明窗口、动画、拖拽 | 拖得动、点她有反应 |
| P16 | 语音 | TTS 出声、音色可选、静音 | 她说话有声音 |
| P17 | 音效与余额 | 音效、余额挂件、平替 | 卸掉 pet/whale 不受影响 |
| P18 | 断网与收尾 | 断网不崩、能交付 | 按 README 装成功 |

**18 小时。**

## 12. 交接卡与消耗

每阶段必写 `阶段记忆\PXX-名字.md`：
`做了什么 / 改了哪些文件 / 怎么验证 / 没做完的 / 下一阶段先做什么 / 坑`

规则：**新阶段先读最近一张 / 卡没写完不算完成 / 只写事实**。

| 每阶段 | ¥1 – 2 |
