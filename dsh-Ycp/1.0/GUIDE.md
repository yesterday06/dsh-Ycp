# 三、设计指南

## 3.1 安装（开发期）

1. 把 `dsh-Ycp\1.0\` 拷到 `D:\OpenAI\仓库\dsh-Ycp\1.0\`
2. 备份 `C:\Users\<你>\.dsh\profiles\desktop` 整个目录
3. 在 profile 的 `package.json` 加依赖与 bundle
4. 重启 Harness（用计划任务脚本，不自杀式重启）

## 3.2 首次配置顺序

```
P03 之后：先改人设第一段 → 试说 → 话风对不对
P05 之后：把记忆目录指向她的家 → 看能不能检索到
P06 之后：设一遍作息 → 到点验证她真的闭嘴
P11 之后：加一个测试站点 → 看她能不能登进去
```

## 3.3 日常使用

| 想干什么 | 去哪 |
|---|---|
| 看她今天干了啥 | 她的今天 |
| 改性格 | 人设 |
| 看她记得什么 | 记忆 |
| 限制她 | 行为 |
| 给她开新网站 | 手 → 浏览器白名单 |
| 给账号 | 账号文件夹 |
| 查错 | 日志 |

## 3.4 扩展新能力

三步：

1. 在 `src/host/capabilities/` 写一个模块
2. 调 `registry.registerTool()` 或 `registerHand()` 注册
3. 在 `扩展\` 放它的配置

**不用改内核。**

## 3.5 排错顺序

```
插件没加载 → 看 main 路径、看日志有没有 "[dsh-Ycp] 已加载"
面板打不开 → 看 HTTP 路由是否挂载、浏览器控制台报错
她说不了话 → 看闸门返回的 reason
她记不住 → 看记忆目录、看检索打分
她打不开网页 → 看白名单、看 Playwright 浏览器二进制
```

## 5.2 运行

| 项 | 估算 |
|---|---|
| 每天说话 | 30–100 次 |
| 每天费用 | ¥0.2–1 |
