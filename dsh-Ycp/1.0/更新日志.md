# 更新日志

## 0.1.0（2026-10-25）首个正式版

### 桌宠

- 透明置顶窗口：拖拽 / 甩抛 / 固定（托盘或 `Ctrl+Alt+P` 解锁）、大小四档、多屏可停。
- 106 个 960×540 透明动画，7 类分组随机轮换；点击、回复时带动作。
- 独立右键菜单、托盘菜单、托盘图标换成她自己的形象。
- 独立聊天小窗：默认只留输入框，可展开记录、可拖动；回复分段显示、按内容自适应字号行数。
- 39 张表情包，按状态/关键词概率出现。
- 气泡贴头顶向上长，长回复不再压住人。

### 状态与行为

- 体力 / 心情 / 饱食三维状态；吃饱恢复快、饿着恢复慢；长时间没人理会自己歇着回体力。
- 事件系统：被夸、被骂、吵架输、被举报、被冷落等直接影响心情。
- 主动性 = 体力 50% + 心情 30% + 饱食 20%；表情包概率随状态浮动。
- 作息 / 主动性权限开关：默认 AI 自己调；主人强制改作息会记 `forced`、心情 -2。

### 饭量账本

- tokens = 她的饭：聊天/上网/发帖按行为记 token。
- 支出/收入两个标签；支出六格：今日预算、今日已用、本月预算、本月已用、总消耗、目前剩余，均带 ≈人民币。
- 收入以人民币为主、≈tokens 为辅；可手记。
- 每日/每月预算可改，见底 10% 主动向主人要；「喂食」跳转充值页。
- 每笔 token 自动生成「token 折算」人民币支出。

### 人设与成长

- 人设直接链接两份性格来源原文（`人设/参考/`，docx + md）。
- 新增 `人设/成长.md`，自动并入每次生成的人设背景；工具 `persona.grow` 让她自己提炼经历。
- 她是 AI、知道主人、知道冀荣佳且知道她们像，仅此而已。

### 接口与模型

- 面板「模型接口」：OpenAI 兼容 API 地址 / Key / 模型名，自定义模型只换思维，不换记忆和人设。
- 个性化签名只由她自己改（`signature.set` 工具），主人面板不可编辑。

### 移除 / 已知限制

- 语音功能移除（界面、合成、播放链路全部下线）；后续再做神经音色。
- 手机运行、断网运行列入下个版本。
- 动画素材上限 960×540，更大尺寸会发虚。
