# dsh-Ycp · 阿闷 0.2.0

住在 DeepSeek Harness 里的桌宠个体。**记忆是本体，对话是平台**——换个入口、清空聊天记录，她还是她。

0.2.0 起**动手能力整层移除**：不能上网、不能点屏幕、不能跑脚本、不能发帖。先把「记忆 + 说话」这一件事做扎实，动手能力以后再从零一点点加。

- 版本：**0.2.0**（能力层移除版）
- 许可：MIT
- 平台：Windows（桌宠窗口依赖 Electron；面板是 DSH Web 插件）
- 语音：默认关（合成链路还在，设置里可开）

## 她现在能做什么

### 记忆（本体）

- **分层**：核心记忆（按重要度每轮必带）+ 相关记忆（按问题检索）+ 此刻 + 最近对话。
- **查重合并**：同一件事写卡时自动并进旧卡，不会越用越乱；文件名由标题生成。
- **重要度 1–5**：决定哪几张卡每轮被带上，不靠「最近改过的」。
- **加权检索**：BM25 × 重要度 × 新鲜度 × 命中次数。
- **每天反思**：从原始记忆里回看，长出长期卡和成长。
- **记忆体检**：重复 / 空 / 超长 / 久未用，一键合并或删除。
- **窗口折叠**：聊太长时，旧的一段压成「聊天 日期 时间」摘要卡，接着聊不断档。
- **原始记忆**：每天一个文件、只追加、不设上限，不进提示词，只供反思和回查。

### 聊天

- 面板「和她说话」：完整聊天记录、可往前翻 30 条一页、发完自动刷新。
- 桌宠总终端：聊天 / 她的空间 / 设置 / 日记。
- 每次说话带多少对话由 `historyChars` 决定（默认 1.6 万字，最大 51.2 万字）。
- 聊天记录存 `状态/对话/历史.jsonl`，只追加、不设上限。

### 状态与外观

- 体力 / 心情 / 饱食三维，事件影响心情，主动性随状态浮动。
- 106 个动画、39 张表情包、托盘菜单、拖拽甩抛、大小四档。
- 状态不只显示：体力低、饿、心情差会影响说话长度和态度，但不报数字。

### 账本

- tokens 就是她的饭：聊天、主动说话都记账，按这一轮真正发出去的上下文算。
- 预算、余额、充值入口；见底会提醒。

### 人设

- `人设/人设.md` 是基础人设，`人设/成长.md` 是她自己长出来的，两份都会交给模型。
- `RULES.md` 是操作手册，每轮注入；0.2.0 版明确写了「你现在没有手」。

## 明确没有（0.2.0）

- 浏览器 / 桌面操作 / 脚本 / 命令 / 平台接口 / 账号接管。
- 面板里的「手」、工具清单、权限开关、白名单。
- 桌宠终端里的 B站 / 抖音 / 小黑盒 / QQ空间 / QQ 页面。

被要求做这些时，她会说「我现在还动不了手，只能记下来」，不假装完成。

## 安装

1. 依赖：Windows + DSH `>= 0.2.1-rc.2`；桌宠窗口用 `~/.dsh/electron/electron.exe`。
2. 在 desktop profile 的 `package.json` 里加 `"dsh-Ycp": "link:<本目录>"`，并在 `dsh.profile.bundles` 末尾加 `"dsh-Ycp"`。
3. 重启 Harness。
4. 家目录：`<数据根>/阿闷/`（数据根默认 `D:\OpenAI\dsh-Ycp`，可用 `DSH_YCP_HOME` 改；名字由 `人物名.txt` 决定）。

## 目录

```
src/host/            宿主：内核 / 器官（记忆·心情·作息·主动）/ 工具注册表 / HTTP
src/client/          面板（React h，源码直载，无构建）
assets/pet/          桌宠 Electron 窗口
assets/character/    动画、形象、图标
assets/memes/        表情包
RULES.md             操作手册（每轮注入）
更新日志.md           版本记录
```
