# dsh-Ycp · 大肥鱼 0.1.0

一个住在 DeepSeek Harness 里的桌宠个体：**会用电脑、有状态、会记账、能自己上网做事**。
不是接了一堆平台接口，是给她一双手——浏览器、桌面、脚本——和一套会随经历变化的性格。

- 版本：**0.1.0**（首个正式版）
- 许可：MIT
- 平台：Windows（桌宠窗口依赖 Electron；面板是 DSH Web 插件）
- 语音：**本版已移除**（效果不达标，后续作为独立方向）

## 能做什么

### 桌宠

- 透明置顶小窗，可拖、可甩、可固定（托盘解锁 / `Ctrl+Alt+P`）。
- 106 个动画，按待机 / 开心 / 吃 / 玩 / 干活 / 打盹 / 数钱分组，随机轮换。
- 右键独立菜单（不挡人）、托盘菜单、可调大小（0.7 / 1 / 1.35 / 1.7）。
- 独立聊天小窗：默认只留输入框，点「📜」展开记录，可拖动；回复在气泡里分段显示。
- 气泡按内容自适应字号和行数；39 张表情包按心情和关键词出现，不是每条都发。
- 托盘图标、插件图标、面板头像都是她自己的动画帧。

### 状态

- **体力**：聊天 / 上网 / 发帖 / 玩耍消耗；睡觉和长时间没人理时恢复；越高越爱主动。
- **心情**：受事件影响（被夸、被骂、吵架输、被举报、被冷落），低到一定程度会自闭、少主动、少发表情包、说话更冲。
- **饱食**：和 tokens 账本挂钩；吃饱恢复快，饿着恢复慢。
- 主动性 = 体力 50% + 心情 30% + 饱食 20%。

### 饭量账本

- **tokens 就是她的饭**：聊天、上网、发帖按行为记 token 消耗。
- 支出 / 收入两个标签；支出显示今日预算、今日已用、本月预算、本月已用、总消耗、目前剩余，每项都带 ≈人民币。
- 「喂食 / 去充值」直接打开 DeepSeek 充值页；每日 / 每月预算可改。
- 收入以人民币为主、≈tokens 为辅；可手记。
- 预算见底 10% 会主动向主人开口，一天只提一次。

### 人设与记忆

- `人设/人设.md` 是基础人设；`人设/参考/` 放性格来源的原文（docx + 可读 md）。
- `人设/成长.md` 是她自己的成长记录，**每次生成回复都会和人设一起交给模型**。
- 工具 `persona.grow`：她可以把经历过 / 想通的事提炼成一句写进成长。
- 记忆检索：标题 ×3 / tags ×2 / 正文 ×1，top-2，实时卡必读；日记不参与检索。
- 面板可编辑基础人设；成长记录单独存，编辑人设不会把它覆盖。

### 模型接口

- 面板「模型接口」可填 OpenAI 兼容的 API 地址 / Key / 模型名。
- 填了就走自定义接口，**记忆和人设不变**，只换思维方式；留空用 DSH 当前模型。

### 双手与边界

- **账号接管**：主人给的账号完全由她经营——登录、发帖、评论、发视频、改资料、回私信，不用逐条请示；只保留风控节奏与验证码停手。

- 浏览器：Edge + CDP，可搜索、打开、点击、填表、登录一次保留状态。
- 桌面：截屏、鼠标、键盘、程序白名单（默认关）。
- 脚本：`fs.read/write/list`、`script.run`、`cmd.run`（默认关）。
- 账号动作有节奏护栏（写动作 ≥8 秒、每天 ≤30 次）；遇到验证码或风控（-352 / -412 / -509）立刻停手。
- **明确不做**：验证码绕过、指纹伪造、换 IP。

## 安装

桌面 profile 用 link 方式安装（开发态）：

```json
"dependencies": { "dsh-Ycp": "link:D:\\OpenAI\\仓库\\dsh-Ycp\\1.0" },
"dsh": { "profile": { "bundles": ["...", "dsh-Ycp"] } }
```

`node_modules/dsh-Ycp` 建 Junction 指向本目录，重启 DSH 即可。
详细步骤见 [安装说明.md](安装说明.md)。

## 家在哪

默认数据根 `D:\OpenAI\dsh-Ycp`（可用 `DSH_YCP_HOME` 覆盖），人物目录名由 `人物名.txt` 决定（默认「大肥鱼」）：

```
<数据根>/<人物名>/
  settings.json
  人设/人设.md  人设/成长.md  人设/参考/
  记忆/（全局卡、归档、实时卡、日记）
  状态/（心情、记账、频率、宠物窗口、备份）
  账号/ 行为/ 外观/ 扩展/
  logs/
```

共用资源（美术、动画、表情包、字体、设计文档）都在插件包 `assets/` 与仓库根目录，不放在人物目录。

## 目录

```

src/client/     面板（React h()，源码直载，无构建）

assets/memes/   表情包
assets/fonts/   上首软糖体
DESIGN.md GUIDE.md PROMPT.md 指令.md 更新日志.md
```
