## 做了什么

- **五个工具**（`src/host/capabilities/script.js`）：
  | 工具 | 边界 |
  |---|---|
  | `fs.read` | 家目录相对路径；≤100KB |
  | `fs.write` | 家目录相对路径；≤256KB；覆盖前备份到 `状态\backups\` |
  | `fs.list` | 最多 200 条，带类型与大小 |
  | `script.run` | 写 Node 脚本并运行，cwd=家目录；成功留在 `扩展\脚本\<名字>.mjs`，失败不当作可复用脚本 |
  | `cmd.run` | 归 `runCommand` 手（默认关）；强制 cwd=家目录，挡掉绝对路径 / `..` / 系统目录变量 / `start`、`del`、`format` 等 |
- **路径护栏**：只收相对路径；盘符、UNC、以 `/` 开头、`..` 越界一律拒；写入前再校验一次落在家里。
- **跑脚本**：用当前 Node（`process.execPath`）跑，20 秒超时、1MB 输出上限；成功后脚本就是你以后能复用的工具。
- **留痕**：读写与运行都进 `行动日志`。

## 坑

- **`process.exit(3)` 在 tool 结果里是 `result.ok=false`，不是注册表 `ok=false`**：注册表包了一层 `{ok:true, result}`，断言要看里面。
- **路径护栏要同时查前缀和解析结果**：只查 `..` 字符串不够，`a/../../b` 也会跑出去；用 `resolve` + `relative` 再判一次。
- **脚本文件失败也会留下**：一开始想着失败删掉，后来改成"不标 kept"，文件留着方便排查；真要清理主人自己删。
- **cwd 是家目录**：脚本里写相对路径会落在家里，别以为还在仓库。
- **黑名单挡不住花活**：`cmd.run` 能拦常见写法，但 shell 本身能做的事很多；不想给她系统权限就别开 `runCommand`。
