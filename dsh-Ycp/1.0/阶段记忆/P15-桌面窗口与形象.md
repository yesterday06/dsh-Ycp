## 做了什么

- **桌宠独立进程**（`assets/pet/`）：插件跑在 Host 里没有 Electron 主进程权限，所以桌宠是一个**自己的 Electron 进程**。Electron 直接用 dsh-pet 已经装好的 `~/.dsh/electron/electron.exe`（v24.18.1），不重复下载、不删旧插件。
- **窗口**：200×200、透明、无边框、置顶（floating）、不进任务栏、默认右下角。
- **拖拽与抛掷**：renderer 发屏幕坐标 → 主进程移动窗口；松手按最近 4 个采样点算速度，交给主进程物理循环（重力 0.9、碰边反弹 0.5/0.55、摩擦 0.82），慢了自动停。
- **动画**：待机（上下浮）、游两圈（左右摆 + 轻微转向）、打个盹（下沉 + zzz）；点一下弹一下、随机气泡台词。
- **右键菜单**：聊天（打开 DSH）、动画（待机 / 游两圈 / 打个盹）、设置（打开 DSH）、收起。
- **宿主与面板**：`GET/POST /pet` 起停查；面板「外观」区可以「放她出来 / 收起来 / 开 DSH 时自动」，显示窗口位置与被点次数。
- **新形象**：重画了一条鱼（大眼、腮红、鳍、气泡），`icon.svg`、面板插图、桌宠三处统一。

## 怎么验证

**一、自检（两条全过）**

```powershell
$n='D:\OpenAI\DeepSeek Harness\resources\runtime\primary-runtime\dependencies\node\bin\node.exe'
& $n 'D:\OpenAI\工作区1\_verify\p15\pet-smoke.mjs'
& $n 'D:\OpenAI\工作区1\_verify\p15\live-smoke.mjs'
```

live 会真的在屏幕上出一个窗口，然后用**真实鼠标事件**（桌面之手）验证：
- 窗口 204×204、状态文件 `ready=true`；
- 点中心 → `reactions` 0 → 1（验收「点她有反应」）；
- 从中心拖到左上方 → 窗口位置移动 220px（验收「桌面上能拖着她走」）；
- 收起后进程消失，无残留。

**二、真启动（在 DSH 里）**

- `GET /pet`：`available=True source=dsh-pet running=False`。
- `POST /pet/start`：`running=True`，窗口在 `1467,827`、204×204。
- 再查：`reactions=0`；`POST /pet/stop`：`closed=True`，之后 `running=False`，没有残留 electron。

## 坑

- **打包后的 Electron 不能拿来跑任意 app**：直接给 `DeepSeek Harness.exe <appdir>` 会被它自己的 main 接管（试过，静默退出）。要用**纯净的 Electron**（dsh-pet 下载的那份），`electron.exe <appdir>` 才认参数。
- **`ELECTRON_RUN_AS_NODE` 必须删掉**：宿主进程带着这个变量，不删的话 electron 会以 Node 模式跑，窗口永远出不来。
- **窗口尺寸会多 4px**：透明无边框窗口在 125% 缩放下 `getBounds()` 返回 204，别拿 200 做死判断。
- **拖拽别用 `-webkit-app-region: drag`**：那样拿不到松手速度，抛不出去；自己算屏幕坐标再 `setPosition` 才有物理效果。
- **`setAlwaysOnTop(true,'floating')` 还不够**：全屏应用/虚拟桌面会盖住，补了 `setVisibleOnAllWorkspaces`。
- **状态文件要节流**：`move` 事件每帧都写盘会卡，120ms 合并一次。
- **测试要自己收尸**：`finally` 里 stop，并删掉测试用的 `状态\宠物\窗口.json`；否则下次读到旧位置。
