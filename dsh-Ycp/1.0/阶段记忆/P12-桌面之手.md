## 做了什么

- **默认关**：`settings.hands.desktop = false`；关着时 `desktop.*` 全部被注册表在入口挡下（`permission`），脚本根本不会跑。
- **实现**：Windows 自带 PowerShell + user32（`System.Windows.Forms` / `System.Drawing` / `Add-Type`），**零依赖**；脚本放在 `src/host/capabilities/desktop.ps1`，首次使用时拷到 `状态\桌面\desktop.ps1`，源文件更新会自动覆盖副本。
- **八个工具**：`desktop.info` / `screenshot` / `click` / `drag` / `type` / `key` / `focus` / `launch`。
- **打字**：剪贴板粘贴（支持中文）；给了 `pid` 会先切窗口，并核对标题里有没有 `expectTitle`，切错窗口就拒打——防止把字打进主人正在写的文档。
- **切窗口**：`SetForegroundWindow` 从后台进程常被系统拒绝，依次试 `ShowWindow` → `SetForegroundWindow` → COM `WScript.Shell.AppActivate` → 按一下 Alt 解锁后再设，最后还不成就报错。
- **程序白名单**：`settings.hands.desktopApps`，只认名字或完整路径（大小写不敏感），空名单谁都不许启动。
- **留痕**：`状态\桌面\最近动作.json`（最近 20 条）；截图落 `状态\截图\desktop-*.png`。
- **接口**：`GET /api/dsh-Ycp/desktop`；面板「手」区显示桌面状态、程序白名单输入、说明。

## 怎么验证

**一、自检（两条全过）**

```powershell
$n='D:\OpenAI\DeepSeek Harness\resources\runtime\primary-runtime\dependencies\node\bin\node.exe'
& $n 'D:\OpenAI\工作区1\_verify\p12\desktop-smoke.mjs'
& $n 'D:\OpenAI\工作区1\_verify\p12\live-smoke.mjs'
```

- 白名单：名字 / 大路径 / 大小写都认；`calc.exe` 不认；空名单全拒。
- 默认关：`desktop.screenshot`、`desktop.launch` 都是 `permission`。
- 开了手但白名单空：启动被拒且不会真启动。
- 真截图：PNG magic 正确、>10KB；`desktop.info` 能列出窗口。

**二、真启动（在 DSH 里，验收两条都过）**

- 默认 `enabled=False`；关着时截图 → `permission`。
- 打开桌面手、白名单只放 `notepad.exe` → `desktop.launch` 成功（找到窗口 pid）。
- `desktop.type` 打「大肥鱼写字测试 2026-10-24」→ 焦点窗口标题变成 `*大肥鱼写字测试 2026-10-24 - Notepad`（星号=未保存）。
- `desktop.key ^a^c` → 剪贴板读回 `大肥鱼写字测试 2026-10-24`，证明字确实进了记事本。
- 收尾 `taskkill`，无残留 Notepad / 无残留 DSH 子进程。

## 坑

- **`SetForegroundWindow` 会静默失败**：后台进程调它常被系统拒绝，必须验证 `GetForegroundWindow` 是否真的切过去了，再决定要不要打字；否则字会打进主人正在用的窗口。
- **`desktop.type` 必须带 `expectTitle`**：标题对不上就拒打，这是最后一道保险；别图省事只传文字。
- **`desktop.key` 也会打到前台窗口**：给 pid 让它先切窗口，别裸发 `^a^c`（我第一次测试就是裸发的，结果改动了前台窗口的选择与剪贴板）。
- **Windows 11 记事本是打包应用**：`Start-Process notepad.exe` 返回的 pid 可能马上失效，真正窗口在另一个同名进程里；`launch` 要轮询找有标题的窗口，别直接用启动器的 pid。
- **PowerShell 控制台默认不是 UTF-8**：脚本开头设 `[Console]::OutputEncoding`，否则 Node 读回来的中文窗口标题是乱码。
- **脚本副本会过期**：`ensureScript` 只在不存在时拷贝会一直跑旧脚本；改成源文件比副本新就覆盖。
- **截屏含隐私**：整屏截图会连主人别的东西一起拍进去；只在她要看屏幕时截，别定时截。
