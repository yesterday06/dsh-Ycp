## 做了什么

- **六道触发**（`src/host/organs/proactive.js`），全部满足才开口：
  1. 醒着 · 2. 主动开关 · 3. 非安静时段 · 4. 今天没超 `dailyLimit` · 5. 状态不极低 · 6. 过了冷却。
- **冷却抖动**：间隔 `everyMin` 分钟，实际在 0.7–1.3 倍之间随机（±30%）。
- **内容来源**：实时卡 → 随机一张全局卡 → 只靠时间背景；来源跟着消息一起存，方便回看。
- **生成**：system 里加「没人在跟你说话」+「你的状态（体力/心情/饿）」，由模型按人设说一句；不写死台词。

- **失败退避**：没 key / 模型报错不存消息，只把下次时间推后 5 分钟，避免每分钟硬撞。
- **节流开关**：默认**关着**（不主动烧钱）；面板「主动」区可开、可调间隔与每天上限、可「现在试一次」（跳过冷却）。

## 坑

- **定时器要挂在 ctx.effect 里**：直接 `setInterval` 不清理，热重载会叠出好几个定时器，一小时说的话翻倍。
- **失败不能占冷却**：一开始想着失败也存 `nextAt`，结果没 key 时每次都推迟 5 分钟——这没问题，但别把失败的消息写进 `messages`，否则面板会显示一句根本没生成的话。
- **默认必须关**：主动是唯一"没人操作也会花钱"的功能；默认开会让主人一装就烧钱。默认关 + 面板一键试。
- **测试夹具的 argv 下标**：`node script.mjs <arg>` 里 `process.argv[1]` 是脚本路径，参数在 `argv[2]`；之前写成 `argv[1]`，删除动作全落在不存在的路径上，看起来执行成功其实没清。
- **来源为空也要能说**：没有实时卡、没有全局卡时，只靠时间背景；别写成"没来源就不说"，那会让她在空家里永远闭嘴。
