## 做了什么

- **五个音效，代码生成**（`src/host/appearance/sound.js`）：22050Hz、16bit、单声道 WAV，正弦波 + 淡入淡出，不下载素材、不加依赖。落地 `状态\音效\`，配方版本号变了自动重生成。
  | 事件 | 用途 |
  |---|---|
  | `click` | 点桌宠 |
  | `speak` | 回话（没开语音时） |
  | `sleep` | 睡觉 |
  | `eat` | 吃饭（留给以后） |
  | `low` | 低余额 |
- **可关、可调**：`settings.sound = {enabled, volume}`；面板「音效」区有总开关、音量滑条、五个试听按钮。桌宠点一下自己播 `click`（音量跟设置）。
- **桌宠播本地音效**：宿主把 file:// 地址与音量放进**环境变量**，preload 读后交给 renderer——不用命令行参数（见坑）。
- **余额**（`src/host/appearance/balance.js`）：和 whale 同一条路——DSH `credentials.resolve('DEEPSEEK_API_KEY')` → `https://api.deepseek.com/user/balance` → 取 CNY 钱包；5 分钟缓存；断网/H TTP 错误时退回上次的值并带错误说明；密钥不落盘、不进日志、不返回给前端。
- **面板**：「她的今天」下方显示 `¥xx.xx` + 进度条（50 元满格）、刷新按钮；低于 `balance.warnBelow`（默认 10）变红、提示「该充了」、响一次 `low`。
- **接口**：`GET/PUT /sound`、`GET /sound/file/*`、`GET /balance?refresh=1`。

## 坑

- **`normalizeSettings` 忘了加 sound/balance**：保存成功但读回永远是默认值，两个测试同时挂才暴露——加字段必须同时改 save 校验和 load 归一。
- **Electron 遇到 `--ycp-click file:///… --ycp-volume 40` 会直接退出（exit -1，无报错）**：file:// 值 + 数字开关的组合触发；换成环境变量 `YCP_CLICK_URL` / `YCP_SOUND_VOLUME` 后正常。桌宠的新开关别走命令行。
- **音效不要用大文件**：点一下 3KB 就够；睡觉 22KB；别拿整段音乐当点击音。
- **余额是钱的事**：key 只从凭据服务取，不写日志、不回前端；失败只报「没 key / 接口 500 / 断网」，不猜数字。
- **低余额提示音只响一次**：轮询每 10 秒一次，不加 `lowSoundPlayed` 会一直叫。
