## 坑

- **包名带大写** `dsh-Ycp`：`pnpm add link:` 装得进，DSH 也认；但 npm 对包名有大小写规则，P18 打 tgz 前先 `npm pack` 试一次，不行就整体改小写（API 前缀 `/api/dsh-Ycp/` 要同步改），别到发版才发现。
- **`dsh --profile p01 web` 是错的**：`web` 会被当成 app 参数，报 `too many arguments`。正确写法是 `dsh --profile p01`——profile 自己就是 web app。
- **`dsh web` 不加 `--no-open` 会真的弹浏览器**：测试时踩过一次，以后一律带 `--no-open`。
- **`/plugins/??…&rev=` 对 rev 很敏感**：手工 curl 不带 rev 或 rev 不对一律 404，这**不代表**客户端没加载；判断依据看页面注入里有没有 `dsh-Ycp/client.js`。
- **计划任务/后台跑测试别用 `Start-Job`**：本机 pwsh 的 job runner 会直接报错退出。改用 `Start-Process` + `-RedirectStandardOutput` 写文件，再按命令行精确收尸。
- **控制台编码**：中文日志在 GBK 控制台是乱码，读文件要显式 `-Encoding UTF8`。
