## 做了什么

- **家目录**：`<DSH_HOME>/Ycp/大肥鱼/`，首次加载自动建 12 个目录，写默认 `settings.json` 与 `人设\人设.md`；再启动只补缺的，已有文件不覆盖。
- **设置读写**：名字（1–24 字、禁控制字符）、启用、模型跟随三个字段；未知字段整份拒绝，绝不写半份。
- **人设读写**：全文读写，上限 64K 字符。
- **原子写 + 写前备份**：先写同目录临时文件再 rename；覆盖前把旧文件拷到 `状态\backups\<时间戳>-<文件名>`。
- **HTTP 三个接口**：`GET /api/dsh-Ycp/state`、`GET|PUT|POST /api/dsh-Ycp/settings`、`GET|PUT|POST /api/dsh-Ycp/persona`；写操作校验同源，body 上限 256 KB。
- **行动日志**：`Ycp\logs\YYYY-MM-DD.log`，建家、保存设置、保存人设、接口挂载都记一行。
- **面板**：读到家路径、目录 12/12、人设字数、设置字节数；能改名字与启用开关并落盘，失败把原因写在面板上。

## 坑

- **PowerShell 5.1 发中文 JSON 会变 `??`**：`Invoke-WebRequest -Body $string` 用 ANSI 编码。要发中文必须 `[System.Text.Encoding]::UTF8.GetBytes($json)` 再传字节；浏览器 fetch 没这个问题（已用 Node 自检验证 UTF-8 正常）。
- **测试别指向真实 `DSH_HOME`**：P01 的 host-smoke 曾真的在 `C:\Users\淡痕\.dsh\Ycp` 建了一套默认家（当时已删）。自检一律先设 `DSH_YCP_HOME` 到工作区。
- **`ctx.inject(['webServer'], cb)` 是异步注入**：路由在回调里注册，回调里用 `inner.effect(...)` 返回 disposer，否则热重载会重复挂。
- **Windows 上 rename 可能被占用**：原子写要留退化路径（直接覆盖），否则保存偶发失败。
- **`ensureHome()` 在 apply 里同步跑**：家建不出来只记日志、不让插件加载失败；状态接口里 `dirs` 会显示缺哪个。
