## 做了什么

- **注册表**（`src/host/capabilities/registry.js`）：
  - `registerTool({ id, description, schema, run, hand? })`：四样缺一样就注册失败，id 重复直接报错，注册返回 `dispose` 可注销。
  - `registerHand({ id, name, description, risk })`：手（能力通道）；内置 `browser / desktop / script / runCommand`，状态从 `settings.hands` 读。
  - `registerAppearance({ id, name, description })`：外观/音效挂件，P15–P17 往这里挂。
- **调用**：`invoke(id, args)` 依次做「找工具 → 查手权限（声明了 hand 才查）→ 校验参数（必填 + 基础类型）→ 执行」；工具抛错折成 `tool-error`，不把异常丢给面板。
- **演示工具**（`capabilities/builtin.js`）：`demo.echo`（原样返回）与 `demo.time`（返回本地时间），外加一个 `placeholder` 外观。
- **接口**：`GET /api/dsh-Ycp/tools`、`POST /api/dsh-Ycp/tools/invoke`。
- **面板「手」区**：列出工具（id / 说明 / 用哪条手）、四条手的开关状态、`demo.echo` 输入框 + 试一下 + 返回结果。

## 坑

- **工具 id 要能当键**：用 `字母开头 + . _ -` 的白名单，`demo.echo` 这种点号命名既好读又能分组；别用中文 id，URL 和日志都会麻烦。
- **注册失败要返回原因**：一开始想直接 throw，结果加载时一个坏工具会让整个插件起不来；改成返回 `{ok:false,error}`，调用方决定要不要停。
- **手权限放在注册表里查**：别让每个工具自己查 `settings.hands`，否则迟早有一条手忘了查；统一在 `invoke` 入口挡。
- **`ctx.effect` 里启动的定时器**：P08 的主动定时器现在和注册表共存；热重载时注册表是新对象，旧定时器若没清会拿着旧 `ctx`——所以定时器必须挂在 effect 上，靠框架清理。
- **演示工具别接外部资源**：`demo.*` 只做纯计算，P10 的真上网工具再单独加权限与统计。
