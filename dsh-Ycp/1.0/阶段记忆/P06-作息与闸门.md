## 做了什么

- **作息**（`行为\作息.json`，`src/host/organs/schedule.js`）：
  - 工作日 / 周末各自的起床、睡觉时间；
  - 午睡（开关 + 起止）；
  - 安静时段（开关 + 起止）；
  - 睡着时：`回一句困的`（reply）或 `完全不理`（silent）。
- **跨夜判断**：23:30 睡、08:00 起这种窗口，连着前一天一起看——周五 23:45 睡下，周六 00:30 仍算睡着，不会因为换了一天、周末作息不同就醒了。
- **五道闸**（`src/host/organs/gate.js`）按固定顺序：
  1. 总开关 → `disabled`
  2. 睡眠 → `sleep`（silent 才挡；reply 放行但带困意）
  3. 安静时段 → `quiet`
  4. 手权限 → `permission`（说话不需要手，这一道实现成 `checkHand`，P11 起用）
  5. 频率 → `rate-limit` + `retryAfterSec`
- **频率记录**：`状态\频率.json`，只留最近一小时；放行的尝试都记一条（模型请求已经要花出去了）。
- **困意提示**：睡着且选 reply 时，system 末尾加「【这会儿】你困得厉害……只回很短的一句」，返回里 `awake=false`。
- **面板「作息」区**：工作日/周末时间输入、午睡与安静时段开关、睡着时二选一、保存；状态行与顶部灯会显示「夜里睡着，到 07:00 起」。
- **设置**：新增 `sayPerHour`（默认 20，1–200）与 `hands`（浏览器开 / 桌面关 / 脚本开 / 跑命令关，P11 起真正用）。

## 坑

- **补丁式保存要叠在磁盘值上**：`saveSchedule` 一开始直接拿 patch 叠默认值，面板只传一个字段时会把整份作息打回默认。现在先 `loadSchedule()` 再叠 patch。
- **跨夜窗口不能只看当天**：只按"今天属于工作日还是周末"判断，周五深夜跨到周六就会被周末作息误判成醒着；必须同时看昨天和今天两个窗口。
- **`$x = if (...) { $bytes }` 会拆数组**：PowerShell 把 byte[] 输出到管道时逐字节展开，`Invoke-WebRequest -Body` 收到的是「123 34 115…」这种空格数字串，服务端 JSON 解析直接失败（报 position 4）。改用普通 if 分支赋值，别再写成表达式。
- **频率挡住的调用不该记账**：只有过了闸、真的要调模型的才记；否则被挡的请求会把自己越锁越死。
- **闸门顺序固定**：总开关关着时，哪怕正睡着也该返回 `disabled`，别让面板显示"睡着"误导人。
