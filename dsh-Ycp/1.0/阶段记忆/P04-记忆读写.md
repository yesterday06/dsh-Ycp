## 做了什么

- **四类记忆目录**：全局记忆 / 归档记忆 / 实时记忆 / 日记，各自一个目录，卡片就是带 frontmatter 的 md。
- **frontmatter 解析**（自己写的小解析器，不加依赖）：
  - `key: value`；`tags: [a, b]` 与 `tags: a, b` 两种写法都认；
  - 没有 frontmatter 也不报错，标题退回正文第一个 `# 标题`，再退回文件名。
- **列卡 / 读卡 / 写卡 / 删卡**：
  - 写：新建或覆盖，覆盖前自动备份；先写临时文件再 rename。
  - 删：先备份再删（软删，能从 `状态\backups\` 捞回来）。
  - 文件名白名单：单层 `.md`、≤80 字、不含路径分隔符与控制字符，`../` 这类越界输入直接 400。
- **日记**：`记忆\日记\YYYY-MM-DD.md`，每次追加 `## HH:mm` 段落；当天没有文件就先建。
- **HTTP 五个接口**：列表、读卡、写卡、删卡、追加日记。
- **面板「记忆」区**：四栏切换（每栏带张数）、列卡（标题 / 描述 / 文件名 / 字数 / 时间）、打开编辑、新建、删除（二次确认）、刷新；日记栏上面多一个「记到今天」的输入框。

## 坑

- **diary 也是「层」**：写卡接口允许写进 diary，测试里因此多出一张 `测试-diary.md`；以后做「日记只追加」的约束时要想清楚是否禁掉直接写。
- **文件名白名单要跟 UI 一致**：面板新建用 `新卡片-YYYYMMDD-HHmmss.md`，含中文、数字、连字符，正则已覆盖；改命名规则时两边一起改。
- **`readdirSync` 在目录被外部删掉时会抛**：先 `existsSync` 挡一道，返回空数组而不是让接口 500。
- **frontmatter 解析故意只做子集**：多行的 `description: |` 还没支持，写了会当成空字符串；要支持得换真 YAML 解析器（P05 看情况）。
- **覆盖写会产生很多备份**：改一次存一次，`状态\backups\` 会堆；P18 收尾统一加「只留最近 N 份」。
