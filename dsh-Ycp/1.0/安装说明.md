# 大肥鱼（dsh-Ycp）安装说明

一个 DSH 插件：给她一个家、一套记忆，三只手（浏览器 / 桌面 / 脚本），加声音、桌宠和余额。装好之后，她在 DSH 的面板里出现，数据只落在自己的家目录。

她的形象是手画的鲸鱼娘：蓝发、鲸尾呆毛、水手卫衣；图标、面板、桌宠共用一张 SVG（`assets/character/whale-girl.svg`）。

## 一、需要什么

| 项 | 要求 |
|---|---|
| 系统 | Windows 10 / 11（桌面手、语音都依赖 Windows 自带组件） |
| DSH | ≥ 0.2.1-rc.2（在 `package.json` 的 `dsh.compatibility` 里写了） |
| 浏览器 | Edge 或 Chrome 任意一个（浏览器手用它的 CDP，不装 Playwright） |
| 语音 | 系统自带 SAPI 音色；中文一般自带「微软慧慧」 |
| 桌宠（可选） | 一台装了 Electron 的机器：`~/.dsh/electron/electron.exe`；装过 dsh-pet 的机器通常已经有了。没有也能用，只是桌宠起不来 |
| 网络 | 说话、搜索、余额要联网；断网时其余功能照常 |

## 二、安装（离线包）

预安装包在 `D:\OpenAI\工作区1\dsh-Ycp-预装\`（文件夹 + zip 各一份，P18 打的）。

1. **备份**：把 `C:\Users\<你>\.dsh\profiles\desktop\` 整个目录复制一份，出问题能退回去。
2. **放置**：把 `dsh-Ycp` 文件夹放到一个固定位置，例如 `D:\OpenAI\仓库\dsh-Ycp\1.0\`（路径别带空格更省事）。
3. **改 profile**：编辑 `C:\Users\<你>\.dsh\profiles\desktop\package.json`：

```json
{
  "dependencies": {
    "dsh-Ycp": "link:D:/OpenAI/仓库/dsh-Ycp/1.0"
  },
  "dsh": {
    "profile": {
      "bundles": [
        "@deepseek-ai/dsh-base",
        "@deepseek-ai/dsh-web-app",
        "dsh-Ycp"
      ]
    }
  }
}
```

保留你原来的其它依赖和 bundle，只加 `dsh-Ycp` 这一项。

4. **重启 DSH**：用你惯用的方式（计划任务脚本重启，别让 DSH 自己杀自己）。
5. **打开面板**：DSH 左侧栏出现「大肥鱼」，点开能看到状态行、人设、声音、外观、手。

## 三、首次配置

1. **人设**：先把「她的人设」第一段改成你想要的性格，保存；用「试说」看话风对不对。
2. **模型**：面板顶部会显示当前模型；没选模型时说话会失败，先在 DSH 里选一个。
3. **账号**：说话和余额都需要 `DEEPSEEK_API_KEY`。在 DSH 的模型设置里填好；余额面板会显示 `¥xx.xx`，没填会明确告诉你。
4. **手**：
   - 浏览器手默认开，默认不限制站点（`*`），想收紧就在「手 → 浏览器白名单」里填域名。
   - 桌面手默认关，要鼠标键盘时再开；开了还要填程序白名单（例如 `notepad.exe`），空名单谁都不许启动。
   - 系统命令 `cmd.run` 默认关，要用再开。
   - 「登录后的动作」默认关：开了她才敢用登录态点赞、评论、发弹幕、填表。
5. **声音**：面板「声音」→ 选音色 → 试听 → 想让她按人设挑就点「按人设配声音」。
6. **桌宠**：面板「外观」→ 放她出来；想开机就有，勾「开 DSH 时自动」。
7. **作息/主动**：按你的时间改；主动发言默认关，要她主动说话再开。

## 四、平台能力（重要，别期待错）

| 平台 | 能做什么 | 前提 / 限制 |
|---|---|---|
| B 站 | 搜视频、看全站排行榜，读页面文字 | 无需登录；只读公开页面 |
| 小黑盒 | 用 Bing 站内搜索找小黑盒的页面，读标题摘要 | 站内搜索接口要签名，所以绕道 Bing；结果可能不全 |
| 抖音 | 搜关键词 | **无登录会被验证码挡住**；工具会如实说「要登录」，不会假装刷到内容 |
| QQ | 往当前打开的 QQ 聊天窗口发一句话 | 桌面手必须开；先在 QQ 里点开那个人的聊天框；工具会核对窗口标题，切错窗口拒发 |
| 登录后的动作 | `browser.login` 打开可见窗口让你登录；之后 `browser.eval` 可在页面执行 JS，`browser.upload` 能传图（背景/头像/表情包），`bili.me` 看资料，`bili.api` 调 B站接口（改资料、发动态、回评论），`site.api` 对抖音/小黑盒/QQ空间做同样的事，`bili.like` / `bili.follow` / `bili.comment` 点赞关注评论 | 必须打开「登录后的动作」手（默认关）。登录态存在她的浏览器 profile 里，**只登你愿意交给她的号** |

登录流程：面板「手 → 浏览器 → 打开登录窗口」→ 在弹出来的 Edge 里登录 B站/抖音/小黑盒 → **直接关掉窗口** → 登录态留下，之后她 headless 也能用。登录态失效时工具会提示重新登录，不会强行继续。

**关于反风控**：这里只做「别像机器人」的节奏控制——写动作最少间隔 8 秒、每天最多 30 次，两个值可以用环境变量 `YCP_ACTION_MIN_MS` / `YCP_ACTION_DAILY_CAP` 调整。**不绕过验证码、不伪造设备指纹、不换 IP**；被风控（`-352/-412`）就停手报错，由你决定下一步。把号完全交给她可以，但风险也在那个号上。

## 五、断网会怎样

| 功能 | 断网时 |
|---|---|
| 面板、人设、记忆、作息、心情 | 正常 |
| 桌宠、语音、音效 | 正常（全在本机） |
| 说话 | 失败并说明原因 |
| 搜索 / 读网页 | 失败并提示「联网搜索失败（可能断网）」 |
| 余额 | 显示上次读到的数，并标明错误 |
| 浏览器 / 桌面 / 脚本 | 本机操作照常 |

## 六、卸载

1. 从 profile 的 `package.json` 去掉 `dsh-Ycp` 依赖和 bundles 里的那一项。
2. 重启 DSH。
3. 她的数据在 `C:\Users\<你>\.dsh\Ycp\大肥鱼\`，想留就留，想清就整目录删掉（**删之前先备份**）。

## 七、常见问题

- **桌宠起不来**：面板会显示「没找到 Electron」。设 `YCP_ELECTRON` 指向 `electron.exe`，或先装一次 dsh-pet 让它把 Electron 下到 `~/.dsh/electron/`。
- **没有声音**：面板「声音」里看系统音色列表是否为空；空的说明系统没装中文语音包。
- **QQ 发不出去**：确认桌面手开着、QQ 窗口标题包含「QQ」、聊天框已经点开。
- **余额一直是旧的**：5 分钟缓存，点「刷新」强制查；报错会写原因。
- **面板白屏**：先看 DSH 日志有没有 `[dsh-Ycp]` 报错；把日志发我。

## 八、安全与隐私

- 密钥只从 DSH 凭据服务读，不写进她的家目录、不进日志、不返回给前端。
- 登录态存在 `状态\浏览器\profile\` 里，等于把账号交到她手上；只登你愿意给的号，「登录后的动作」不用时关掉。
- 她可以自己改资料、发动态、回评论——这是你的授权，不是平台认可的自动化；被风控或封号的风险由账号承担。
- 截图会存 `状态\截图\`，整屏内容都可能拍进去；不需要时别开桌面手。
- `cmd.run` 是黑名单护栏，不是沙箱；真正的边界是那条手开不开。
- 所有动作都记 `logs\YYYY-MM-DD.log` 和对应的「最近动作」文件，事后能查。
